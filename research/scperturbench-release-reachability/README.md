# scPerturBench: released-result inventory

The [Cheerful Duck report](https://cheerfulduck.com/research/audits/scperturbench-training-direction) describes the reversed training direction in the cellular-context baseReg and baseMLP implementations. This companion inventory checks whether those implementations and the released baseline result rows occur at the same source commit.

At commit `6e24e7a9827e55d4567d2139427be9af0d1e7a6c`, four source files and the repository's provenance statements are checked against pinned Git blob hashes. Four released result tables contain **1,736 baseline rows across 12 datasets**: 868 baseReg rows and 868 baseMLP rows.

These counts establish a connection to released benchmark material. They do not prove that every row was generated by the inspected source, and they do not compute corrected predictions, method rankings or paper conclusions. Resolving those questions requires the relevant original inputs, configuration and a complete rerun.

## Reproduce

Run with Python 3.11 or newer and network access; no third-party packages are required:

```sh
python research/scperturbench-release-reachability/analyze_released_results.py
```

The script downloads source and tables from the immutable upstream commit, rejects hash mismatches and writes `result.json`. The committed [verified result](verified-result.json) preserves the passing inventory independently of CI artifact retention. On 8 September 2026, a fresh local run produced a JSON object identical to the artifact from [run 34136543901](https://github.com/dnncha/Dnncha/actions/runs/34136543901).
